INSTALLATION GUIDE

Install and Open PaperRss

The current release is not notarized by Apple. If macOS says the app cannot be opened or is damaged, choose either option below:

Option 1: Run terminal trust command (Recommended)
sudo xattr -rd com.apple.quarantine /Applications/PaperRss.app
Option 2: Allow in macOS System Settings

Open System Settings → Privacy & Security, scroll down to the Security section and click "Open Anyway".

📌 Beta Status & Apple Notarization: PaperRss is currently in active Beta with frequent updates. Once the feature set matures, we will provision an official Apple Developer account for code notarization, eliminating gatekeeper prompts. For full details, see the GitHub README.
