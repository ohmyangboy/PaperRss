# macOS 文章阅读自定义快捷键

PaperRss 在 macOS「键盘快捷键」窗口中为「文章阅读」分组提供自定义按键组合能力：保留 C / V / K / J / M / F / O / Space 默认键的同时，允许用户按 VS Code 风格录制 `⌘ ⇧ ⌥ ⌃ + 主键` 组合，并为每个动作切换「防误触」（连按两次）/「单次触发」。

## 适用范围

- **平台**：macOS 独占入口（帮助菜单「键盘快捷键…」或 `⌘/`）。
- **可自定义分组**：仅「文章阅读」：切换对照翻译、查看 AI 摘要、查看上一篇、查看下一篇、切换收藏、切换禅模式、打开原文、向下阅读。
- **不可自定义分组**：「栏目导航」与「全局」保持系统固定，面板只做展示。
- 输入文字、选择正文或打开 AI 交互弹层时不触发；`⌘C` 与 `⌘V` 始终保留系统复制、粘贴行为。

## 按键组合

- 主键按**物理键位**识别（AppKit `keyCode` ↔ DOM `event.code`），与输入法、键盘布局无关。
- 支持主键区字母、数字、标点、Space、方向键、Return、Delete、Home / End / Page Up / Page Down。
- 修饰键支持 `⌘`、`⇧`、`⌥`、`⌃`；不支持 Tab、Esc、功能键与小键盘按键。
- 每个动作只保留一个组合；冲突处理：
  - 与其他文章阅读动作冲突：提示占用者，并可一键跳转到该动作修改。
  - 与应用固定键（栏目/列表方向键、返回时间线、正文字号、`⌘/`）或系统菜单快捷键冲突：直接拒绝并提示占用名称。
- 「防误触」开启时，同一组合需在 2.5 秒内连按两次才执行，面板键帽右侧以 `×2` 小字标示；关闭后按一次即执行。
- 系统预设键默认开启「防误触」；用户录制带 `⌘ ⇧ ⌥ ⌃` 的组合时自动关闭该动作的防误触（视为明确意图），裸键保留当前设置，也可在弹层中随时手动改回。

## 新增：打开原文（默认 O O）

- `O` 连按两次在默认浏览器打开当前文章的原始链接；没有原始链接时给出提示。
- 可在面板中改绑为任意可用组合，或改为单次触发。

## 持久化

- 绑定写入本地 `UserDefaults`（`PaperRss.readerShortcutBindings`），启动即恢复；旧数据缺失字段自动回落默认值。
- 存储中若出现系统保留组合，应用与阅读器页面都会忽略该绑定并回落默认键，系统行为不受影响。
- 帮助窗口右侧滚动条与设置页一致，使用正文同款细浮层滚动条。
