# macOS 文章章节导航轨道（Article TOC Rail）

PaperRss 在 macOS 桌面端为长文章提供原生、紧凑且轻量的右侧章节导航轨道（TOC Rail），帮助用户在沉浸式纸感阅读中快速把握全文结构并精准定位。

## 适用范围与激活条件

- **平台**：macOS 桌面端独占（iOS 端保留原生滚动体验，不注入该组件）。
- **激活条件**：
  - 文章高度超过视口高度的 2 倍（`scrollHeight > innerHeight * 2`）；
  - 提取到的有效导航锚点不少于 3 个（标题及长段落补充锚点）。
- **若不满足条件**：轨道不呈现，阅读器保持标准原生滚动。

## 核心交互与视觉设计

1. **静止自动隐去与交互浮现（Autohide & Float-in）**：
   - 静止阅读时轨道平滑淡出隐去，保持版面纯粹沉浸；
   - 在页面滚动、鼠标滑向右侧边缘或轨道、拖拽翻页或键盘聚焦时即时浮现（`opacity: 1`），并在闲置后自动优雅淡出。
2. **紧凑刻度短线（Codex 式布局）**：
   - 垂直居中固定在文章右侧，默认短线宽度为 8px；
   - 随当前阅读位置实时高亮当前章节（浅色模式深灰，深色模式高亮浅灰）。
3. **悬停波峰展开与即时卡片预览**：
   - 鼠标悬停在轨道上时，刻度短线呈抛物线波峰展开（当前 22px，相邻 16px / 11px）；
   - 悬停 150ms 弹出精致半透明纸质预览卡片，呈现章节标题及第一段正文摘录。
4. **精准阅读重心锚定**：
   - 点击章节刻度后，平滑滚动至人眼黄金视线重心（视口上方 ~20%，约 64px~160px）；
   - 点击文章首锚点直达大标题顶部（`top: 0`）。
5. **全轨道无缝命中与拖拽映射**：
   - 按钮采用 100% 垂直等分几何热区，彻底消除亚像素与边缘命中错位；
   - 支持按住轨道连续拖拽滚动，实时线性映射全文阅读进度。
6. **键盘与无障碍支持**：
   - 支持 `Tab` 键聚焦各章节按钮，`Enter` 或 `Space` 键即时导航；
   - 完整支持 VoiceOver / 辅助功能标签及多语言即时本地化。
