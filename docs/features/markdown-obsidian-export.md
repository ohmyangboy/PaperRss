# Markdown 与 Obsidian 导出

PaperRss macOS 端支持将当前文章导出为 Markdown 文件，或直接保存到用户选择的 Obsidian vault 目录。

## 使用方式

1. 在文章阅读器中打开一篇文章。
2. 点击阅读工具栏中的下载图标，选择 `导出 Markdown…` 或 `保存到 Obsidian…`。
3. 普通导出使用系统保存面板；Obsidian 保存使用目录选择面板，可以选择 vault 根目录或其中的子目录。
4. 确认保存，文件会以文章标题作为默认文件名，并使用 `.md` 扩展名。Obsidian 保存遇到重名时会自动使用 `-2`、`-3` 等后缀，不覆盖已有笔记。

## 导出内容

- YAML frontmatter：标题、PaperRss 文章 ID、阅读状态、收藏状态、订阅源、作者、发布日期和原文 URL（存在时）。
- 已清洗的文章正文，转换为 Markdown 标题、段落、强调、链接、图片、引用、列表、代码块和基础表格。
- 图片和链接使用文章原始地址解析后的 HTTP(S) URL。
- 脚本、样式、表单、内嵌框架和不安全 URL 不会写入导出文件。

导出操作只使用阅读器已经加载或缓存的正文，不会为导出额外抓取网页，也不会触发 AI 请求。文件写入用户选择的位置，不会修改 PaperRss 的本地数据库，也不需要 Obsidian 插件或 Obsidian API。首版不会保存 vault 路径。
