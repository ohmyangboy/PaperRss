# 智能编排与杂志版面规则

- **Status**: implemented; isolated layout verification completed
- **Issue**: https://github.com/ohmyangboy/PaperRss/issues/32
- **范围**：继续既有智能编排；不包含提交、推送或发布。

## 版面目标

默认智能编排保持输入顺序，用主次、共同栏边和有限的图文组合建立杂志感。每页最多一个主视觉；短讯与图片按组排布，避免逐卡填入最低列产生碎片化空白。内容直接排在纸面上，常驻卡片底色、圆角框和图片外框全部取消；悬停和选中仍有状态反馈。

## 统一网格与字体

| 项目 | 规则 |
| --- | --- |
| 版心 | 最大 1280pt，常规页边 32pt，中缝 40pt；双页对开门槛 860pt（适配 MacBook 等笔记本窗口） |
| 栏 | 每叶最多两小栏，小栏最小 220pt，栏距 24pt |
| 分区 | 组内条目间距 24pt，横向分区间距 32pt |
| 标题 | 主稿 34pt、跨栏图文 22pt、侧重短讯 19pt、窄栏稿 18pt |
| 正文与来源 | 摘要 13–15pt，来源日期 13pt；主稿文字间距 10pt，其他稿 6pt |
| 对齐与悬停 | 正文保持栏线对齐；悬停与选中底色在内容四周外扩 8pt，不移动图片或文字 |
| 图片 | 普通主图铺满图框；侧重稿左图右文，先固定旁图宽度（不超过正文区 32%），再按标题、摘要和来源的总高度匹配图高；画廊横图统一为 1.85:1 |

数字是当前产品参数，不是固定纸张或通用印刷标准。没有配图不保留图片区；文字和点击区域始终保持实测自然高度。图片统一按 cover 居中裁切填满图框；旁图随文字增高时不扩大宽度，避免反过来挤窄文字并继续推高正文。

## 组合规则

| 内容形态 | 组合方式 | 约束 |
| --- | --- | --- |
| 整叶专题 | 左叶只放一篇主稿，图片占正文区一半左右（净高 ≥ 460pt，图片 ≥ 220pt 且占 ≥ 48%）；右叶连续图文 | 配图、足够空间与至少三篇配稿必须同时成立；右叶内容不足时恢复主稿加画廊 |
| 图像或长文字开篇 | 左叶主稿 + 右叶 1–4 条侧重稿 | 每页最多一个主稿；侧栏保持正常文字预算，仅允许额外增加最多 12pt 组间距 |
| 一幅图文与数条短讯 | 一叶整栏图片，另一叶两行短讯或短讯纵组 | 两组共享起点；短讯纵组必须与对侧图片配对 |
| 连续同类小图或短稿 | 相邻双稿 | 两稿高差不超过 56pt 或组高的 24%，避免高图拖出相邻空洞 |
| 纯文字 | 每叶两小栏，按行组成短讯组 | 不采用四条独立瀑布列，也不优先退回两条全宽列表 |
| 页尾空间不足 | 局部减少摘要或改旁图 | 保留 3–4 行标题预算；放不下进入下一页 |
| 已知末页 | 单叶自然高度收尾 | 最大 720pt；未加载结束时不宣告末页 |

左右两组从同一横向起点排列，下一分区从较低底线之后开始；不把剩余空间分摊到正文。候选同时比较组内空洞、左右高度差、图片尺度与篇数，避免为了多放一篇全面缩小文字、删图或压缩标题。取消按文章序号放大图片、逐张追逐最低列的规则。无图主稿最多三行 30pt 标题，避免长推文形成五行巨型标题；并列稿与画廊优先于连续宽列表。

整叶专题在初次编排时优先考虑已收藏稿或有效摘要不少于 160 字的稿件；其他有摘要的配图稿按文章 ID 的稳定散列约四分之一进入候选，相邻版不重复使用。摘要长度只是当前列表投影可用的内容量线索，并不等同于全文字数或真实重要性。已展示页的已读、收藏变化沿用缓存，不触发当前页跳动。

文章仍只消费输入的连续前缀，不跳过难排文章补洞。开篇先主稿、再右侧稿；后续按分区向下，每区先左组再右组，组内按行从左到右。键盘空间导航沿用文章实际几何。

## 实现与稳定性

`MagazineEdition.groups` 提供去重后的连续有序分组。`MagazinePaginator` 在同一次测量中完成开篇、分区组合与分页，视图仅按文章 ID 渲染位置。单页与双页的纸面宽高、背景中缝和点击区域都来自同一布局结果：单页没有中缝，涉及单页的翻页使用淡入，任何单篇稿件都不跨双页中缝。单叶窄窗使用既有自然高度布局，低高度或大字切为连续流。自动回退不修改用户保存的翻页偏好。

`MagazineStoryStyle` 同时提供测量与展示所用的字体、间距、行数与图片预算。图片下载完成不重排当前页。`MagazineEditionCache` 保留已展示页面，追加时只重排未展示尾部；后台计算可取消，并校验范围与版本。窗口、字号或阅读范围变化时通过文章 ID 恢复位置。已读、收藏和纯颜色变化不影响几何。
