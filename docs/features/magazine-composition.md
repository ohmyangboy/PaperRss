# 智能编排与杂志版面规则

- **Status**: implemented; isolated layout verification completed
- **Issue**: https://github.com/ohmyangboy/PaperRss/issues/32
- **范围**：继续既有智能编排；不包含提交、推送或发布。

## 版面目标

默认智能编排保持输入顺序，用主次、共同栏边和有限的图文组合建立杂志感。每页最多一个主视觉；短讯与图片按组排布，避免逐卡填入最低列产生碎片化空白。内容直接排在纸面上，常驻卡片底色、圆角框和图片外框全部取消；悬停和选中仍有状态反馈。

## 统一网格与字体

| 项目 | 规则 |
| --- | --- |
| 版心 | 最大 1280pt，常规页边 40pt，中缝 40pt；双页对开门槛 860pt（适配 MacBook 等笔记本窗口） |
| 页眉与页边距 | 页眉区（本期选读 + 页码）合计 76pt：标题行 20pt、下间距 16pt、纸面上下各 20pt；上下页边保持一致 |
| 内容缩放 | 字体、行距与来源信息统一按 0.95 呈现，为页边距留出呼吸感；图片仍按栏宽与既定比例铺满，图文结构与对齐规则不变 |
| 栏 | 每叶最多两小栏，小栏最小 220pt，栏距 24pt |
| 分区 | 组内条目间距 24pt，横向分区间距 32pt |
| 标题 | 主稿 34pt、跨栏图文 22pt、侧重短讯 19pt、窄栏稿 18pt |
| 正文与来源 | 摘要 13–15pt，来源日期 13pt；主稿文字间距 10pt，其他稿 6pt |
| 对齐与悬停 | 正文保持栏线对齐；悬停与选中底色在内容四周外扩 8pt，不移动图片或文字 |
| 图片 | 普通主图铺满图框；侧重稿左图右文，先固定旁图宽度（不超过正文区 32%），再按标题、摘要和来源的总高度匹配图高；画廊横图统一为 1.85:1 |

数字是当前产品参数，不是固定纸张或通用印刷标准。没有配图不保留图片区；文字和点击区域始终保持实测自然高度。图片统一按 cover 居中裁切填满图框；旁图随文字增高时不扩大宽度，避免反过来挤窄文字并继续推高正文。

## 组合规则

| 内容形态 | 组合方式 | 约束 |
| --- | --- | --- |
| 整叶专题 | 左叶只放一篇主稿，图片占正文区一半左右（净高 ≥ 460pt，图片 ≥ 220pt 且占 ≥ 48%）；右叶连续图文 | 配图、足够空间与至少三篇配稿必须同时成立；右叶内容不足时恢复主稿加画廊 |
| 图像或长文字开篇 | 左叶主稿 + 右叶 1–4 条侧重稿，矮的一叶继续接稿 | 每页最多一个主稿；侧重稿只受页面高度限制；两叶各自从自己的游标向下推进 |
| 一幅图文与数条短讯 | 一叶整栏图片，另一叶两行短讯或短讯纵组 | 两叶独立推进，不要求共享起点；短讯纵组无需与对侧图片配对 |
| 连续同类小图或短稿 | 相邻双稿 | 两稿高差不超过 56pt 或组高的 24%，避免高图拖出相邻空洞 |
| 纯文字 | 每叶两小栏，按行组成短讯组 | 不采用四条独立瀑布列，也不优先退回两条全宽列表 |
| 页尾空间不足 | 局部减少摘要、改旁图或收缩竖排图 | 保留 2–4 行标题预算；放不下才进入下一页 |
| 内容已排完仍有空余 | 末张竖排图增高收口 | 只增高不拉伸（cover 裁切），以方形为上限，并列双稿不拉伸 |
| 已知末页 | 单叶自然高度收尾 | 最大 720pt；未加载结束时不宣告末页 |

左右两叶各自维护自己的纵向游标：下一组连续稿件放进剩余空间更大、且能容纳它的一叶，因此矮的一叶会继续接稿，而不是等待较高的分区底线。候选组仍用组内空洞、篇数与占用高度共同评分，占用高度的权重在剩余内容估不满时提高，让大图与整栏稿收口；内容充足时保持并列短讯的紧凑节奏。取消按文章序号放大图片、逐张追逐最低列的规则。无图主稿最多三行 30pt 标题，避免长推文形成五行巨型标题；并列稿与画廊优先于连续宽列表。

整叶专题在初次编排时优先考虑已收藏稿或有效摘要不少于 160 字的稿件；其他有摘要的配图稿按文章 ID 的稳定散列约四分之一进入候选，相邻版不重复使用。摘要长度只是当前列表投影可用的内容量线索，并不等同于全文字数或真实重要性。已展示页的已读、收藏变化沿用缓存，不触发当前页跳动。

文章仍只消费输入的连续前缀，不跳过难排文章补洞。开篇先主稿、再右侧稿；后续左右两叶各自向下推进、先补空间更大的一叶，组内按行从左到右。键盘空间导航沿用文章实际几何。

## 页眉收紧与逐叶填满验证（2026-09-13）

- 页眉区由 104pt 收紧到 56pt（`verticalInset` 28→12、`headingSpacing` 28→12）；随后为纸面呼吸感回调到 76pt（`verticalInset` 20、`headingSpacing` 16，横向页边 32→40），仍明显小于最初的 104pt。
- 字体、行距与来源信息统一乘 `MagazineStoryStyle.contentScale = 0.95`，内容整体略收 5%；图片继续按栏宽与既定比例铺满，1.85:1 画廊比例与主图高度预算不变。
- 分区组合由“左右共享起点”改为“左右各自维护游标”：矮的一叶继续接稿，不再为对齐较高的分区留下整块空洞；页尾空间不足时优先收缩竖排图或退回侧重稿。
- 内容排完后叶底仍有余量时，末张竖排图增高收口（`MagazinePaginator.flushLeafTails`），只增高不拉伸，以方形为上限，并列双稿与整叶主稿不参与。
- 翻页宿主在分数尺寸下会让不透明图层在纸面右/下缘露出 1px 黑线：`MagazineTurnSurface` 现在在宿主下铺舞台色实底，宿主图层与 Metal 图层使用同一舞台底色兜底，快照封面裁掉越界像素，并清理任何遗留的快照与渲染器。
- 折叠翻页（宽屏对开才走 Metal 折页）在抬起初期只从外缘露出目标页的空白纸面，过半后再淡入正文；着色器以目标页右缘留白为纸面色，避免外缘出现一条被裁切的下一篇文章正文，任何进度都不产生黑色缝隙。
- 回归样本（1450×1250/1450×1000/1250×900 的混合图文，40 篇）逐页填充率 99–100%（末页除外）；05 页同构样本的矮叶空洞从约 366pt 消除到页底余量 < 40pt。
- `MagazinePerformanceTests` 56 项、`MagazineFoldEffectTests` 27 项、`MagazineEditionTests` 7 项通过；完整 App feature 回归 102 项通过。
- **Manual UI verification required**：真实订阅数据下的整页观感、页边呼吸感、末页收尾与图片增高裁切效果仍需在隔离窗口中人工确认；本轮未做提交或发布。

## 实现与稳定性

`MagazineEdition.groups` 提供去重后的连续有序分组。`MagazinePaginator` 在同一次测量中完成开篇、分区组合与分页，视图仅按文章 ID 渲染位置。单页与双页的纸面宽高、背景中缝和点击区域都来自同一布局结果：单页没有中缝，涉及单页的翻页使用淡入，任何单篇稿件都不跨双页中缝。单叶窄窗使用既有自然高度布局，低高度或大字切为连续流。自动回退不修改用户保存的翻页偏好。

`MagazineStoryStyle` 同时提供测量与展示所用的字体、间距、行数与图片预算。图片下载完成不重排当前页。`MagazineEditionCache` 保留已展示页面，追加时只重排未展示尾部；后台计算可取消，并校验范围与版本。窗口、字号或阅读范围变化时通过文章 ID 恢复位置。已读、收藏和纯颜色变化不影响几何。

## 空杂志不自动开页与同步排版取消修复（2026-09-13）

- 修复“有文章却显示暂无文章”的偶发问题：视图更新可能落在已取消的宿主任务上下文里，而 `MagazinePaginator` 的取消检查会据此把整期版面算成空页，并随输入被缓存，直到下一次输入变化才恢复。现在同步排版不响应宿主任务取消；只有 `updateAsync` 的后台编排显式开启 `cancelsWithTask`。
- 空订阅不再自动翻开空书：自动开页计时器要求版面非空，没有文章时默认展示“暂无文章”，不显示可翻开的封面；内容到达后才按一拍封面节奏自动展开。键盘、滑动与点击的开页入口同样被空版面拦截。
- 回归：`testSynchronousCompositionIgnoresAmbientTaskCancellation`、`testEmptyMagazineStaysClosedUntilArticlesArrive` 已加入；`MagazineFoldEffectTests` 25 项、`MagazinePerformanceTests` 55 项、`MagazineEditionTests` 7 项通过，App feature 回归 99 项通过，macOS 宿主构建通过。
- **Manual UI verification required**：真实订阅下的空源、切换订阅与刷新并发的自动开页观感仍需在隔离窗口中人工确认；本轮未提交或发布。
