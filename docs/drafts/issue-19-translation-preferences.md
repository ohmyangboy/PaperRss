# 翻译偏好与原位替换翻译

- **Status**: accepted
- **Issue**: https://github.com/ohmyangboy/PaperRss/issues/19

## 已确认行为

AI 功能设置中合并翻译目标语言与翻译偏好。默认上下文对照翻译，颜色仅提供跟随主题和自定义，浅深色独立保存。自动译文色以主题强调色混合 35% 次级文字色，降低饱和度；对比度不足 4.5:1 时向正文色收敛。自定义初始色为 PaperRSS 暗绿 #5F7355。旧版色板选项回落为跟随主题，已有自定义颜色保留。

设置顺序为目标语言、翻译模式、并排的浅深色颜色选择、预览、居中恢复默认按钮。模式、颜色及更新通道共用 32pt 高的紧凑胶囊分段控件，自定义颜色右侧显示原生颜色选择器。

替换模式原位显示译文，悬浮或键盘聚焦显示原文；使用 Grid 按较长内容预留高度，仅进行 150ms 透明度过渡。减少动态效果设置下即时切换。保留原文节点、链接、选择及语义结构。未完成或失败的译文保留原文。

配置兼容旧数据，保存其他 AI 设置不丢失显示偏好。展示切换复用缓存和增量桥接，不重新请求模型或重载文章。保留同期 Qwen 模型适配改动。本轮不提交、不发布、不关闭 Issue。
