# 模型翻译适配与连接探测

- **Status**: accepted
- Issue: https://github.com/ohmyangboy/PaperRss/issues/21

用户已批准实现：模型级自动/通用/单条用户消息/Qwen-MT 兼容翻译适配。已知 Qwen-MT 自动选择翻译协议；未知名称通过有限连接探测提出切换建议，由用户采用并保存。协议探测通过不宣称模型只能翻译。

翻译适配使用单段请求、语言规范化、现有有界并发与缓存，连接测试复用翻译入口。功能选择标识并禁用不适用组合，运行时也阻止。保留旧配置，默认自动，适配方式进入缓存指纹。探测结果仅在对应草稿修订有效；不保存凭据或模型原始输出。

验收：请求契约、旧数据兼容、别名探测、角色错误不误判、鉴权/限流不重试、取消与草稿失效、段落对应与路由限制；执行 core、feature、macOS 构建和隔离 GUI 验收。真实供应商测试无凭据时明确记录未验证，不发布或提交。

2026-09-06 追加批准：统一思考能力解析与请求构造，按实际官方端点识别协议，自定义接口支持手动协议覆盖。OpenRouter 模型目录提供动态选项，缓存绑定端点、模型和获取时间（24 小时）；添加/刷新模型和功能选择可更新，异步结果校验配置与凭据未变。其他已核验端点使用官方规则，未知只提供服务默认。旧失效档位保留并提示重选，MT 显示不适用；补齐官方语言映射及截断检测。无自动收费探测，不把 HTTP 200 宣称为思考生效证据。
