# PaperRss 公开文档

`docs/` 是随 GitHub 仓库版本化的公开知识库，不是官网发布目录；官网唯一源码位于 `website/`。

## 内容导航

| 类型 | 位置 | 收录内容 |
| --- | --- | --- |
| 已接受草案 | [`drafts/`](drafts/) | 维护者已批准、等待实现的功能规格 |
| 技术调研 | [`research/`](research/) | 经审核、脱敏且可长期复用的研究 |
| 功能说明 | [`features/`](features/) | 已实现的用户可见行为与使用说明 |
| 技术说明 | [`technical/`](technical/) | 稳定的架构、协议和运维知识 |
| 审计记录 | [`audits/`](audits/) | 特定时间点的代码或架构审计 |

探索记录、待批准 spec 与实施 tickets 属于本地 `.scratch/`，不进入公开文档。Agent 工作流由 [`.agents/docs/development-workflow.md`](../.agents/docs/development-workflow.md) 定义。
