# 02 — 交付 V 智能摘要快捷键

**What to build:** 用户在文章阅读态裸按 V 时，可以直接查看已有摘要，或在缺少摘要时显式发起生成，而不会重复计费或绕过摘要可见性设置。

**Blocked by:** 01 — 建立无冲突的阅读快捷键入口并交付 C 对照翻译。

**Status:** resolved

- [x] 已有完整或未完成摘要时，按 V 展开摘要且不发起新的模型请求。
- [x] 没有摘要时，按 V 生成并展开摘要；正文缺失时沿用可读错误反馈。
- [x] 摘要模块被设置隐藏时不生成、不修改设置，并提示用户先开启模块。
- [x] 其他 AI 请求进行且当前没有摘要时不排队、不取消已有任务，并给出稍后再试提示。
- [x] 现有摘要操作提供 V 快捷键帮助和辅助功能提示。
- [x] 专项测试、完整测试、构建和应用启动验证通过。

**Answer:** V 已接入现有摘要状态与生成路径，优先展开缓存，隐藏模块或 AI 忙碌时给出明确提示。运行时未主动触发付费生成；入口、门禁与状态分支由测试和 Debug 构建验证。
