# PaperRss macOS Feed 提醒

## 目标

为 macOS 版 PaperRss 增加两项彼此独立、默认关闭的提醒能力：Dock 未读徽标，以及运行期间定时刷新发现新增未读文章时发送的系统汇总通知。

## 已确认范围

- 仅 macOS 提供提醒设置；应用退出后不执行刷新或通知。
- Dock 徽标统计全部有效订阅源的当前未读总数：`1...99` 显示精确值，超过 99 显示 `99+`，零未读或关闭时清空。
- 系统通知仅由非前台的定时刷新触发；启动、手动、订阅管理和系统后台刷新不触发。
- “新增未读”仅指本轮首次写入本地数据库且最终仍为未读的文章；既有文章更新和同步状态为已读的新条目不计入。
- 每轮刷新最多发送一条通知，展示新增未读总数和最多三个订阅源；更多来源显示剩余来源数，并使用默认提示音。
- 通知权限只在用户主动开启通知开关时申请。拒绝或撤销权限时保持开关关闭，并提供 macOS 通知设置入口。
- 点击通知后激活主窗口、导航到“未读”列表并清除此前文章选择。
- 关闭通知开关不撤销系统授权，也不移除历史通知。

## 工单与依赖

1. `01-report-new-unread-refresh-results.md`：刷新来源与新增未读结果。
2. `02-dock-unread-badge.md`：Dock 未读徽标，可与 01 并行。
3. `03-scheduled-refresh-summary-notifications.md`：依赖 01、02。
4. `04-open-unread-from-notification.md`：依赖 03，并完成真实 macOS 验收收口。

## 验收边界

代码、自动化测试、桌面构建、macOS Xcode Debug 构建和真实 Debug 应用启动由实现代理完成。系统通知授权、真实横幅及点击回跳必须由用户首次开启通知时触发，保留为最终人工验收，代理不得为了测试擅自改变系统通知权限。
