**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] `1...99` 显示精确值，超过 99 显示 `99+`；零未读或关闭时清空。
- [x] 阅读、全部已读、删除订阅及同步状态变化后实时更新。
