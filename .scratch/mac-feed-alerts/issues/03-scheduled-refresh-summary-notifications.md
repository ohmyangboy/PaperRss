# 03 — 让后台定时刷新发送可控的汇总通知

**What to build:** 用户可独立开启系统通知；当运行中的 Mac 应用不在前台且定时刷新发现新增未读文章时，每轮收到一条数量与来源汇总通知。

**Blocked by:** 01 — 让刷新结果准确报告本轮新增未读文章；02 — 让用户可选显示 Dock 未读徽标。

**Status:** resolved

- [x] 在“提醒”分组增加独立、默认关闭的系统通知开关。
- [x] 仅用户开启时申请提醒和默认提示音权限，应用启动不主动申请。
- [x] 权限拒绝或撤销后开关保持关闭，并提供打开 macOS 通知设置的入口。
- [x] 只有非前台的定时刷新发现新增未读时通知；其他刷新来源不通知。
- [x] 前台发现更新时完全跳过，不延迟补发。
- [x] 每轮最多一条，正文展示最多三个订阅源，更多来源显示剩余数量。
- [x] 部分 Feed 失败时仍汇总成功获取的新增未读文章。
- [x] 权限、刷新来源、前后台策略、汇总格式和单轮去重测试通过。
- [x] 按仓库验证规则重新编译并启动应用验证。

## Answer

已实现仅对非前台定时刷新生效的单轮汇总通知策略，并延迟到用户开启开关时才请求提醒与声音权限。拒绝或撤销权限会关闭功能并展示系统设置入口；汇总、来源限制和跳过策略均有回归测试。
