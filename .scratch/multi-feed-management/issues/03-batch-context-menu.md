# 03 — 多选 Feed 批量右键上下文菜单（Context Menu）

**What to build:**
多选多个 Feed 时，在选中项上右键触发批量操作菜单，支持批量标记已读、批量移动分类（包含“无分类”和“新建文件夹并移入”）、批量复制链接以及带确认提示的批量删除。

**Blocked by:**
02 — 侧边栏支持 Feed 多选与中间文章流聚合渲染

**Status:** completed

- [x] 实现多选状态判断，若选中 Feed 数量大于 1 则渲染批量 Context Menu
- [x] 支持“标记选中源全部已读”功能
- [x] 支持“批量移动至文件夹”子菜单（展示已有文件夹、无分类及新建文件夹弹窗）
- [x] 支持“复制订阅链接”（多条 URL 用换行符连接写入剪贴板）
- [x] 支持“批量取消订阅/删除”，触发带影响数量提示的确认 Alert 弹窗
