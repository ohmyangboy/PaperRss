# 已接受的功能草案

本目录只保存维护者明确批准、等待实现的公开规格。

## 收录规则

- 文件名固定为 `issue-<N>-<slug>.md`。
- 文档头部包含一行 `- **Status**: accepted` 和原始 GitHub Issue 链接。
- 实现完成后，按长期价值整理到 `documents/features/` 或 `documents/technical/`；没有独立价值时删除本草案。
- Agent 只有在维护者明确确认后，才能放弃 accepted 方案。
