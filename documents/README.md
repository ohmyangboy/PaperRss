# PaperRss 公开文档

- `documents/` 是随 GitHub 仓库版本化的公开知识库，不是官网发布目录；官网唯一源码位于 `website/`。
-`documents/` 非规则文档，用以了解项目和历史决策，只有显示引用才做参考。且可能有时效性，如果实际工程不一致，以实际代码为准。

## 内容导航

| 类型 | 位置 | 收录内容 |
| --- | --- | --- |
| 归档 | [`drafts/`](drafts/)、[`research/`](research/) | 历史草案与调研，只读留存，不代表当前实现 |
| 功能说明 | [`features/`](features/) | 已实现的用户可见行为与使用说明 |
| 技术说明 | [`technical/`](technical/) | 稳定的架构、协议和运维知识 |
| 审计记录 | [`audits/`](audits/) | 特定时间点的代码或架构审计 |

`documents/` 只收录可长期复用的公开知识。
